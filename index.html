O que é o Tio das Ofertas

Um serviço automatizado de curadoria de ofertas que publica produtos com dados reais da API oficial da Shopee Brasil: preço atual, desconto real, avaliações e vendas. Nada de preço inventado, estoque fictício ou urgência falsa — se o dado não vem da API oficial, não publicamos.

An automated offer-curation service that publishes products with real data from the official Shopee Brazil API: current price, real discount, ratings and sales. No invented prices, fake stock or false urgency — if it doesn't come from the official API, we don't publish it.

Transparência

  • Somos um serviço automatizado — se perguntarem, dizemos sempre.
  • Os links que publicamos são de afiliado: se você compra por eles, podemos receber comissão do marketplace, sem custo extra pra você.
  • Não vendemos, não enviamos produtos e não cuidamos de entrega — a compra acontece 100% na Shopee.
  • Preços podem mudar após a publicação; o valor válido é sempre o exibido no site do marketplace.
